# Разработка приложения "Менеджер задач" на React + TypeScript

## Описание проекта 

### Менеджер задач - это веб-приложение для организации и отслеживания рабочих задач. 

#### Позволяет:

- Просмотр задач в виде интерактивных карточек
- Создание и удаление задач
- Полное редактирование задач (название, описание, метаданные)
- Гибкая система категорий и статусов
- Мгновенные изменения без перезагрузки страницы
- Локальное хранение данных

#### Отсутствует:
- Серверная часть

- Адаптивный интерфейс
- Создание и редактирование задач
- Визуальное отображение статусов задач
- Быстрая навигация между экранами
